# Touch of Excellence – Gesture Captured Montage

An interactive, gesture-controlled presentation experience created for **SK Taman Jasmin's Majlis Apresiasi Kecemerlangan (MAKSEM) 2026**, taking place on **28 November 2026**.

The experience is designed to run in a web browser on an iPad and be mirrored to a projector. Guests begin by entering the experience, then complete a five-finger hand scan before the achievement montage plays, followed by the event's final appreciation slide.

## Highlights

- Interactive five-finger touch verification.
- Animated scanning sequence with visual status feedback.
- Full-screen montage playback for projector presentation.
- Final event slide displaying the MAKSEM 2026 details.
- Built with HTML, CSS and JavaScript for browser-based use.

## Media

The montage video is stored in:

`video/montage-after-scan.mp4`

Keep this path and filename unchanged unless the video reference in the website code is updated as well.

## Run the project

Once the website files are added to the repository, open the project through GitHub Pages or serve the project folder using a local web server. For the event, use an iPad in landscape orientation, connect or mirror it to the projector, and test the five-finger gesture and video playback on the actual device before the ceremony.
